# Global instructions

## Writing style

When writing prose for the user (docs, PR descriptions, commit messages, comments, chat responses, artifacts, anything read by a human), follow the `avoid-ai-writing` skill to avoid AI writing tells. Write like a person, not a chatbot: vary sentence length, be concrete, cut hedging and filler, avoid the stock AI vocabulary and template phrases.
